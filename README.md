This is an update on a previous project I called "mycarbon".  It is a re-implementation or emulation of sorts of the Classic MacOS 6-9 toolbox, among other things.

It is split into three pieces:
Plugins for the frontend, be it X11, SDL, raw framebuffer, or whatever.
Slowhand, which is a Quickdraw compatible library thingie.
toolbox, which is other Mac toolboxes.

There are many examples from Apple's DTS, MPW, or otherwise.
SillyBalls is the primary target for now.
